## 🚀 How to Run Manually (No Python Required)

You can run this portfolio manually in two ways:

### Option 1: One-Click Double Click (Recommended)
1. In your file explorer, navigate to this portfolio folder (`Documents\Portfolio`).
2. Double-click the file **`Start-Portfolio.bat`**.
3. It will automatically launch **`index.html`** in your default web browser (Google Chrome, Microsoft Edge, Brave, Firefox, etc.).

### Option 2: Open HTML Directly
1. Right-click **`index.html`** or **`projects.html`**.
2. Select **Open with** -> **Google Chrome** (or your preferred browser).
3. That's it! Everything works 100% offline and locally via `file://`.
